Supported in Browser (GitHub Pages)

  • Images: JPG, PNG, WebP, AVIF, BMP (resize + target-size solver)
  • Vectors: SVG metadata/comment/whitespace/decimal minifier
  • Office: PPTX, DOCX, XLSX, ODP, ODT (shrinks embedded media!)
  • Archives: ZIP recompression + multi-file ZIP bundling

Need PDF, HEIC, Video, Audio, Fonts, or Zstd?

Browser sandboxes cannot run Ghostscript, FFmpeg, or FontTools natively at full speed. Run the included Python studio or deploy the Docker container in one command: 

git clone https://github.com/Jaspreet-Bhatia-SI/compressor.git
cd compressor && pip install -r requirements.txt
uvicorn app:app --port 7860
